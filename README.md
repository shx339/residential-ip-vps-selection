## 住宅 IP、原生 IP、双 ISP、家宽 VDS，四个词说的不是一件事

**住宅 IP（Residential IP）** 指 IP 的注册主体是家庭宽带运营商，在 IP 数据库里被标成 ISP/Residential，而不是 Datacenter。平台风控认的就是这个标签。

**原生 IP（Native IP）** 指 IP 的注册地和服务器实际所在地一致。美国机房分配真正的美国段，不是拿别处的 IP 套一层美国 CDN。

**双 ISP** 指这个 IP 同时带有两个运营商的属性标记。相比单 ISP，它在风控系统里的可信度更高一些，但本质仍然是 IP 库里的属性字段，不是物理线路。

**家宽 VDS** 是把整台机器托管在美国居民住宅里，走当地运营商装的光纤，一根线只给一个用户。IP 的 ASN 归属就是运营商本身，和普通家庭用户没有区别。

按可信度排，市面上的产品大致是三档：

1. **机房 IP 套一层住宅属性**。ASN 一查就露，风险分通常偏高。最便宜，也最容易在严格平台上翻车。
2. **共享 NAT 住宅 IP**。多人共用一个出口，其中一个人跑垃圾邮件或者做扫描，整条 IP 进黑名单，你的号跟着受牵连。有些商家还会在条款里写“禁止长时间占用”。
3. **真家宽独享静态 IP**。贵，但干净、独享、ASN 归运营商。

判断自己手上这台机器属于哪一档，下单前三分钟能做几件事：用 ipinfo.io 查 ASN 和 company type，看归属是运营商还是云厂商；用风险评分工具看这个 IP 的分数和黑名单命中情况；直接问商家这批 IP 是不是循环销售、有没有免费换 IP。

最后一条尤其值得问。有主打真家宽的商家在官方说明里写得很直白：只保证是真家宽，不保证 IP 纯净度长期不变，同一批 IP 会循环销售，也没有免费换 IP 的政策。真家宽和干净，本来就是两件事。买之前默认“贵的一定干净”，容易失望。
